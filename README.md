# כמה התייקרה המכולת שלך? 🛒

אתר ציבורי שעוקב אחר מחירי סל מצרכים יומיומי ברשתות השיווק הגדולות בישראל,
על בסיס נתוני **חוק שקיפות המחירים** - קובצי המחירים המלאים שכל רשת מחויבת בחוק לפרסם.

## מה יש כאן

- **מדד סל המכולת**: 42 מוצרי יסוד (חלב, ביצים, לחם, גבינות, מוצרי מזווה, שתייה, מוצרי בית) במחירי 6 רשתות: שופרסל, רמי לוי, Carrefour, יוחננוף, אושר עד וטיב טעם, מתעדכן מדי יום.
- **גרף מדד לאורך זמן**: איך השתנה מחיר הסל בכל רשת.
- **מחשבון סל אישי**: בונים סל משלכם ורואים כמה הוא עולה בכל רשת, איפה הכי זול, וכמה הסל שלכם התייקר.

## איך זה עובד

```
┌──────────────────┐   cron יומי    ┌─────────────────────┐
│ קובצי מחירים של  │ ─────────────▶ │ pipeline/           │
│ הרשתות (חוק      │   GitHub       │ fetch_prices.py     │
│ שקיפות מחירים)   │   Actions      │ (il-supermarket-    │
└──────────────────┘                │  scraper)           │
                                    └─────────┬───────────┘
                                              ▼
                              data/prices-YYYY-MM-DD.json
                                              ▼
                        docs/data/index.json (אגרגציה לאתר)
                                              ▼
                        docs/ - אתר סטטי ב-GitHub Pages
```

- הסל נבחר לפי **ברקודים זהים** בין הרשתות (אותו מוצר בדיוק), מתוך סניפי האונליין של הרשתות כדי שההשוואה תהיה הוגנת.
- הרשתות והסניפים: שופרסל ONLINE (413), רמי לוי תלפיות (1), קרפור אונליין (471), יוחננוף (1), אושר עד (1), טיב טעם (2).
- ההשוואה בין הרשתות נעשית רק על **הסל המשותף** - מוצרים שזמינים באותו ברקוד בכל הרשתות (כיסוי משתנה לפי רשת; אושר עד לדוגמה מוכרת מוצרים רבים תחת ברקודים משלה, לכן הכיסוי שלה חלקי יותר).
- הכל חינמי: GitHub Actions + GitHub Pages.
