# כמה התייקרה 🛒

**אותו סל קניות, שש רשתות, מחיר אחד אמיתי — מדי יום מחדש.**

🔗 **[לאתר החי — לחצו כאן](https://victoria-aflalo.github.io/kama-hityakra/)**

## למי זה מיועד?

לכל מי שקונה מכולת בישראל ורוצה לדעת איפה הסל שלו הכי זול — בלי אפליקציה, בלי הרשמה, בלי שטויות.

## מה האתר עושה?

- **השוואת 6 רשתות בזמן אמת** — שופרסל, רמי לוי, קרפור, יוחננוף, אושר עד וטיב טעם. המחירים נשאבים מדי בוקר מקבצי המחירים החוקיים שכל רשת מפרסמת.
- **סל משותף** — מדד יומי של 18 המוצרים שקיימים באותו ברקוד בכל שש הרשתות, כדי שההשוואה תהיה הוגנת. כל רשת מציגה את כיסוי הברקודים שלה ביושר.
- **קטלוג של 620 מוצרים** — מוצרי המזון הנמכרים ביותר בישראל, עם תמונות, ואיתור מבצעים אמיתיים מהיום.
- **סריקת קבלה** — מעלים קבלה והסל מתמלא לבד להשוואה. כל העיבוד בדפדפן שלכם.
